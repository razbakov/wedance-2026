# Clean Studio

Minimal, product-forward style for landing pages, app store assets, and explainer materials. Lets the product speak.

## Mood

Clean, bright, professional, trustworthy, modern

## Color Palette

| Color           | Hex       | Usage                              |
| --------------- | --------- | ---------------------------------- |
| **White**       | `#FFFFFF` | Background (always)                |
| **Black**       | `#000000` | Headlines, icons                   |
| **WeDance Red** | `#F1023D` | Logo "We" only, minimal accents    |
| **Green**       | `#48BB78` | Promotional badges                 |
| **Dark Navy**   | `#1E293B` | CTA buttons, search bars           |
| **Gray**        | `#6B7280` | Subheadlines, secondary text       |

## Typography

| Use           | Font        | Weight  |
| ------------- | ----------- | ------- |
| Headlines     | **Poppins** | Bold    |
| Subheadlines  | **Poppins** | Regular |
| Icon labels   | **Poppins** | Medium  |
| CTA buttons   | **Poppins** | Bold    |
| Footer        | **Poppins** | Bold    |

- Poppins for everything — one font family, different weights
- Headlines: large, black, centered
- Subheadlines: gray, noticeably lighter

## Imagery

- **App screenshots** in phone mockups (3 phones, overlapping, slight rotation)
- **Line-style icons** — black, consistent stroke weight, no fill
- **Green pill badge** for promotional messaging
- No photos, no illustrations — product UI only

## Layout Principles

- White background, generous whitespace
- Vertical flow, everything centered
- Top-to-bottom hierarchy: logo → badge → headline → subheadline → screenshots → icons → CTA → footer
- Icon row: 6 icons in one horizontal line with 2-line labels
- CTA section: dark navy pill button + QR code + URL side by side

## Do / Don't

### Do

- White background with black text
- Green pill badges for promotions
- Dark navy buttons for CTAs
- Line-style icons for features
- Personalize CTA with festival name
- Show the product via phone mockups

### Don't

- Dark backgrounds
- Photos or illustrations
- Filled/solid icons
- Multiple badges stacked
- Generic "Sign up" — always mention the festival
