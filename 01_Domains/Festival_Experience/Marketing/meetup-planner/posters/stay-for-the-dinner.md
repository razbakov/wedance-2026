# Poster — "Stay for the Dinner"

## Concept

Respects the dance as the reason they're here, then positions the group dinner as the unexpected highlight. Simple upgrade framing — dance is great, dinner makes it better.

## Copy

**Headline (large):**

> You came for the dance. Stay for the dinner.

**Subheadline:**

> Group dinners for festival dancers. 4-6 strangers, one restaurant, zero awkwardness.

**CTA:**

> Scan to join — first 10 spots free

**QR code** → landing page with UTM `?utm_source=poster&utm_campaign=[festival-slug]&utm_content=[location]`

**Footer:**

> Rides · Rooms · Dinners · Partners · Adventures

## Design Specs

| Element     | Value                                  |
| ----------- | -------------------------------------- |
| Size        | A3 (297×420mm)                         |
| Orientation | Portrait                               |
| Background  | Dark (stands out on white venue walls) |
| Font        | Bold sans-serif, high contrast         |
| QR code     | Bottom-right, ~8cm                     |
| Colors      | Brand colors + white text              |
| Placement   | Bathrooms, chill zone, near schedule   |
| Print qty   | 5-10 per festival                      |
