## Channel Overview

### 1. WhatsApp Groups

**What:** Festival-specific group chats, city dance community groups, style-specific groups.
**Why:** Highest trust, highest conversion -- dancers already check these daily. Messages feel like friend recommendations, not ads.
**Format:** Short text + link. No images (they get lost in scroll). One message, not a wall of text.
**Who posts:** Kirill directly, or asks a known community member to share.

### 2. Facebook Event Pages / Groups

**What:** The official festival event page, city dance groups (e.g. "Salsa Munich", "Bachata Berlin"), style groups.
**Why:** Facebook groups are where dancers plan festival trips. Event pages have a captive audience of confirmed attendees.
**Format:** Longer post with context. Can include a preview image/screenshot of the schedule. Pin-worthy.
**Who posts:** Kirill posts in groups he is a member of. For groups he is not in, he asks an insider.

### 3. Instagram Stories / Reels

**What:** SDTV Instagram (510K followers), WeDance account, tagged stories from dancers.
**Why:** Discovery channel for new users. Stories create urgency (24h). Reels have viral potential.
**Format:**
- Stories: screenshot of schedule + swipe-up link + countdown sticker
- Reels: 15-30s screen recording of scrolling/filtering the schedule, with trending audio
**Who posts:** Kirill via SDTV or WeDance account.

### 4. YouTube Community Tab

**What:** SDTV YouTube community post (133K subscribers).
**Why:** Reaches a different segment -- dancers who consume video content. Good for pre-festival hype.
**Format:** Image post with text and link. Can include poll ("Which workshop are you most excited for?").
**Who posts:** Kirill.

### 5. Direct Messages / Personal Shares

**What:** Kirill personally sends the link to 10-20 known dancers going to the festival.
**Why:** Seeding. These become the first users AND the first organic sharers.
**Format:** Casual DM: "Hey, we built an interactive schedule for [festival] -- thought you'd find it useful. [link]"

## Timeline and Actions

### T-14 (Two weeks before festival)

**Goal:** Plant the seed. Get the link in front of early planners.

| Channel | Action | Message Type |
|---------|--------|--------------|
| WhatsApp | Share link in festival group with utility hook | Utility / Insider tip |
| Facebook event page | Post with schedule preview image | Utility |
| Facebook city/style groups | Post announcing the interactive schedule | Utility |
| Instagram Stories (SDTV) | Story with schedule screenshot + link sticker | Utility |
| Direct messages | Send to 10-20 known attendees | Personal seed |

**Key message angle:** "The schedule just dropped -- here's a way easier way to browse it than staring at that PDF."

---

### T-7 (One week before)

**Goal:** Drive return visits and build anticipation. Catch the second wave of planners.

| Channel | Action | Message Type |
|---------|--------|--------------|
| WhatsApp | Re-share with social proof hook ("200 dancers already checked it") | Social proof |
| Facebook event page | Comment on existing post with updated numbers or new feature | Social proof |
| Instagram Stories | Poll: "Which workshop are you picking?" + link | FOMO / Engagement |
| YouTube community tab | Image post with poll about workshops | FOMO |

**Key message angle:** "One week out -- have you planned your workshops yet? Dancers are already filtering by style."

---

### T-3 (Three days before)

**Goal:** Urgency. "Last chance to plan" energy.

| Channel | Action | Message Type |
|---------|--------|--------------|
| WhatsApp | Short reminder with FOMO hook | FOMO |
| Instagram Stories | Countdown sticker + "3 days" + link | FOMO |
| Instagram Reels | 15s screen recording of filtering workshops by style | Utility + FOMO |

**Key message angle:** "Festival in 3 days. Popular workshops fill up fast -- check the schedule now so you don't miss your favorites."

---

### T-1 (Day before)

**Goal:** Last push for planners packing their bags.

| Channel | Action | Message Type |
|---------|--------|--------------|
| WhatsApp | "See you tomorrow! Bookmark this for the weekend" | Utility |
| Instagram Stories | "Save this link for the festival" + link sticker | Utility |

**Key message angle:** Keep it short. "Tomorrow! Bookmark the schedule -- you'll need it between workshops."

---

### During Festival (T+0 to T+end)

**Goal:** Be the go-to reference. Drive real-time usage. Capture organic shares.

| Channel | Action | Message Type |
|---------|--------|--------------|
| WhatsApp | Morning message: "Today's workshops at a glance" with link | Utility |
| Instagram Stories | Live story from festival + "check what's on now" link | Utility + Social proof |
| Instagram Stories | Re-share any dancer stories that mention the schedule | Social proof |

**Key message angle:** "Between workshops? Check what's next." Keep it service-oriented, not promotional.

---

### Post-Festival (T+1 to T+7)

**Goal:** Capture feedback. Document results for the next festival and for organizer outreach.

| Channel | Action | Message Type |
|---------|--------|--------------|
| WhatsApp | Thank you + "How was the schedule? Reply with feedback" | Feedback |
| Instagram Stories | "Thanks [festival]! X dancers used the interactive schedule" | Social proof (for next festival) |
| Facebook event page | Comment with results: "X people used it, most popular workshops were..." | Social proof |

**Key message angle:** Close the loop. Thank people. Share a stat. Ask what to improve.

## KPIs per Channel

| Channel | Primary KPI | Secondary KPI | How to measure |
|---------|------------|---------------|----------------|
| WhatsApp | Click-throughs (UTM) | Replies / questions | UTM: `utm_source=whatsapp&utm_medium=message` |
| Facebook event page | Click-throughs (UTM) | Comments / reactions | UTM: `utm_source=facebook&utm_medium=event` |
| Facebook groups | Click-throughs (UTM) | Post reach (if visible) | UTM: `utm_source=facebook&utm_medium=group&utm_campaign=GROUPNAME` |
| Instagram Stories | Link clicks (native analytics) | Story views, sticker taps | SDTV insights + UTM: `utm_source=instagram&utm_medium=story` |
| Instagram Reels | Video views, profile visits | Saves, shares | SDTV insights + UTM in bio link |
| YouTube community | Post impressions, link clicks | Poll votes | YouTube analytics + UTM: `utm_source=youtube&utm_medium=community` |
| Direct messages | Replies, click-throughs | Organic re-shares by recipients | Manual tracking |
