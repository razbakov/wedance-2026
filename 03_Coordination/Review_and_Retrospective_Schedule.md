## Retrospectives

Retrospectives reflect on *how the team works* — not what was delivered (that's the experiment review) or whether governance is current (that's the artifact review).

### When to run

- **After each significant milestone:** pilot festival launch, first organizer partnership, first paid user
- **Every 2-3 dispatch cycles** if no milestone has occurred
- **Ad-hoc** when a major process failure occurs (e.g., agents blocked for >1 week, duplicate work discovered)

### How it works

**Step 1 — Gather data** (Coordinator dispatches all agents in parallel):
Each agent self-reports:
- What went well in the last period?
- What blocked you or slowed you down?
- What would you change about how we work?

**Step 2 — Synthesize** (Coordinator):
Combine agent reports into a retrospective document covering:
- What worked (keep doing)
- What didn't (stop or change)
- Process waste identified (duplication, merge conflicts, bottlenecks)
- Proposed changes (specific: update policy X, add rule Y to agent Z)

**Step 3 — Decide** (Delegators review):
- Alex and Kirill review the retrospective report
- Approve, amend, or reject each proposed change
- Approved changes are applied to agent definitions, policies, or the work board

**Step 4 — Close:**
- Record the retrospective in `03_Coordination/Meeting_Records/`
- Set the next retrospective trigger (next milestone or date)
- Verify previous retrospective's changes were implemented

### Retrospective record format

Save each retrospective as `03_Coordination/Meeting_Records/YYYY-MM-DD_Retrospective.md` with:
- Period covered
- Participants (which agents reported)
- Keep / Stop / Change items
- Decisions made
- Next retrospective trigger

## Agent Evaluation

Quarterly, per each role's Delegation Canvas. The delegator reviews each agent on:

1. **Output quality** — against the role's key metrics
2. **Boundary compliance** — any escalation failures or policy violations?
3. **Tension sensing** — did the agent raise useful tensions, or execute silently?
4. **Driver alignment** — did the agent's work serve the organizational driver?
5. **Collaboration** — did the agent ask for help, give peer feedback, include learnings?

Evaluation results are recorded in `02_Roles/<Role_Name>/` as `YYYY-MM-DD_Evaluation.md`.
