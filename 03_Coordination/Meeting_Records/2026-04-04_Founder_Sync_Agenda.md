## Part 1: What we built (presentation — 15 min)

**"We set up WeDance governance using Sociocracy 3.0."**

### 1. Primary Driver

Dance event information is scattered across Facebook groups, WhatsApp chats, Instagram stories, and physical flyers. Dancers struggle to discover events; organizers waste effort promoting across scattered channels.

### 2. Strategy: "Test Festival Schedule first, at one real festival"

- B2C first: we upload a festival's static schedule as an interactive digital version, share it in the festival's WhatsApp/Facebook group
- If dancers use it, approach the organizer with usage data to bridge into B2B
- Success metrics: 20%+ open rate, 3+ return visits per dancer, organic shares

### 3. Organization Structure

- 50/50 partnership (Alex + Kirill)
- 3 domains: **Festival Experience** (active), Discovery + Marketplace (dormant)
- 9 AI agent roles

| Alex manages | Kirill manages | Shared |
|-------------|----------------|--------|
| Product Lead | Designer | Analyst |
| Engineer | Partnership Manager | |
| Ops Manager | Marketing Lead | |
| Autopilot | | |
| Coordinator | | |

### 4. How agents work

- **Pull system:** agents only work on items moved to "Ready" by founders
- **Autopilot** reads the work board, dispatches agents, reports to founders
- **Agents draft, humans send** — no external comms without approval
- All work delivered via PRs
- WIP limit: 1 item per agent

### 5. Four policies

| # | Policy | Key point |
|---|--------|-----------|
| P1 | Agent Boundaries | What agents can/can't do autonomously. Agents draft, humans send. |
| P2 | Decision-Making | Operational (agent) → Tactical (delegator) → Strategic (partnership by consent) |
| P3 | Data & Privacy | GDPR, minimal collection, no selling |
| P4 | Collaboration | Ask-for-help protocol, peer feedback, involve affected parties |

### 6. Agent deployment plan (G-001)

- **Wave 1 (now):** Product Lead + Operations Manager
- **Wave 2 (before pilot):** Engineer + Analyst
- **Wave 3 (closer to launch):** Designer + Partnership Manager + Marketing Lead
