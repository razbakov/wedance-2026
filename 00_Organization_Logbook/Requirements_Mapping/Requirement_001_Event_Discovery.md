# Requirement: Event Discovery

**Actor:** Dancers, Newcomers
**Domain:** Discovery

## Need
Dancers need to find events, classes, and festivals in their city from a single source so that they can participate without relying on scattered channels. Newcomers need a guided entry point so that they don't give up before finding their community.

## Priority
High

## Type
Governance

## Notes
This is the core requirement — directly mirrors the primary driver. Everything else depends on solving discovery first. Initial validation focuses on festival schedules as the entry point (see Requirement 002).
