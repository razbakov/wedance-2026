## Purpose
**Primary Driver:** Running experiments generates ongoing operational work — converting schedules, maintaining data, handling user questions, keeping the platform running day-to-day. Neither founder has time for this.
**Main Requirement:** Handle the daily operational work that keeps experiments running and the platform functional.

## Key Responsibilities
- Convert static festival schedules (PDF, images, Instagram) into structured data
- Publish and maintain interactive schedules on the platform
- Monitor platform health and flag issues to Engineer
- Handle user questions and feedback (draft responses for review)
- Maintain governance and operations backlogs across domains
- Coordinate data handoffs between roles

- Extracting accurate data from inconsistent static sources (PDFs, photos, Instagram posts)
- Keeping schedules updated when organizers make last-minute changes
- Operating reliably during festival weekends (high-traffic, time-sensitive)
