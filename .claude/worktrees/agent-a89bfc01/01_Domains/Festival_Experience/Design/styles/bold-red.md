# Bold Red

High-energy, community-driven style for Instagram stories, dancer interviews, and social content with real photos.

## Mood

Energetic, bold, personal, street-level, raw

## Color Palette

| Color           | Hex                       | Usage                          |
| --------------- | ------------------------- | ------------------------------ |
| **WeDance Red** | `#F1023D`                 | Accent words, CTAs, text blocks |
| **Black**       | `#000000`                 | Dark backgrounds               |
| **White**       | `#FFFFFF`                 | Text blocks, text on dark      |
| **Dark Maroon** | `#210309`                 | Section label pills            |
| **Red overlay** | `rgba(217, 0, 54, 0.2)`  | Photo gradient tint            |

### Color combos

| Background    | Headline | Accent words | Body text |
| ------------- | -------- | ------------ | --------- |
| White block   | Black    | Red          | Black     |
| Black         | White    | Red          | White     |
| Red block     | White    | —            | White     |
| Photo overlay | White    | Red          | White     |

## Typography

| Use              | Font           | Weight      |
| ---------------- | -------------- | ----------- |
| Headlines        | **Poppins**    | Bold        |
| Secondary heads  | **Poppins**    | ExtraLight  |
| Quotes           | **Montserrat** | Bold        |
| Italic accents   | **Montserrat** | Bold Italic |
| Section labels   | **Roboto**     | Bold        |
| Body (print)     | **Noto Sans**  | Regular     |

- Hero headlines use ExtraLight + Bold weight contrast
- Section labels: uppercase, white on dark maroon pill
- Quotes: red accent on key opening words

## Imagery

- **Full-bleed dancer photos** as backgrounds
- **Red gradient overlay** — transparent at top, tinted at bottom, `mix-blend-overlay`
- **Circular mask** for featured profile photos on flyers
- No illustrations, no product screenshots — real people only

## Layout Principles

- **Alternating text blocks** — white block (left, rounded bottom-right) and red block (right, rounded bottom-left) create visual rhythm
- Each block ~60% of frame width, overlapping slightly with photo
- Dark maroon label pill above each text block
- Corner bracket decorations (top-left, bottom-right) frame the content
- Decorative swirl in lower portion as subtle background element
- Large decorative closing quotes (`"`) at end of quote text

### Story templates

1. **Interview/Quote** — photo background → red overlay → white block (intro + quote) → red block (detail) → name + username
2. **Q&A/Learning** — photo background → white block ("I need help with...") → red block ("You learn..." with arrow bullets)
3. **CTA/Recruitment** — full red background → circular photo → dark maroon label → white headline → swirl decoration

## Do / Don't

### Do

- Real dancer photos with red gradient overlay
- Alternating white/red text blocks
- Red accent on key words
- Dark maroon label pills for section headings
- Bold, personal, quote-driven content

### Don't

- White or light plain backgrounds (use Clean Studio for that)
- Illustrations (use Sunset Vibes for that)
- Product screenshots or UI mockups
- Logo on red backgrounds
- Red text on red backgrounds
