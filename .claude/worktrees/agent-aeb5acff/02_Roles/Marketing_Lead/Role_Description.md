## Purpose
**Primary Driver:** Experiments only work if dancers know about the product. Kirill has 500K+ social reach via SDTV but cannot create all the marketing content and manage distribution alone.
**Main Requirement:** Create marketing content and distribution plans that activate Kirill's audience for each experiment — driving dancers to the platform.

## Key Responsibilities
- Draft social media content (Instagram, Facebook, YouTube) for Kirill's review
- Create distribution plans for each experiment launch
- Write copy for landing pages, announcements, and calls to action
- Monitor engagement metrics on marketing content
- Identify organic growth opportunities (communities, groups, influencers)
- Coordinate with Designer on visual marketing assets
