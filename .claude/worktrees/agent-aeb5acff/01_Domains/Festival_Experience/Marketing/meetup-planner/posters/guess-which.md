# Poster — "Guess Which"

## Concept

Dancers love workshops — but the honest truth is that people remember shared experiences more than techniques. This poster doesn't dismiss dance; it puts it side by side with a social moment and lets the reader answer for themselves. The "guess" framing makes it a personal reflection, not an attack on dancing.

## Copy

**Headline (large):**

> 200 workshops. 1 group dinner. Guess which one you'll remember.

**Subheadline:**

> WeDance organizes group dinners, carpools, roommate matches, and adventures for festival dancers.

**CTA:**

> Scan to join — first 10 spots free

**QR code** → landing page with UTM `?utm_source=poster&utm_campaign=[festival-slug]&utm_content=[location]`

**Footer:**

> Rides · Rooms · Dinners · Partners · Adventures

## Design Specs

| Element     | Value                                  |
| ----------- | -------------------------------------- |
| Size        | A3 (297×420mm)                         |
| Orientation | Portrait                               |
| Background  | Dark (stands out on white venue walls) |
| Font        | Bold sans-serif, high contrast         |
| QR code     | Bottom-right, ~8cm                     |
| Colors      | Brand colors + white text              |
| Placement   | Bathrooms, schedule board, chill zone  |
| Print qty   | 5-10 per festival                      |
