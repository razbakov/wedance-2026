# Poster — "Better Crew"

## Concept

Minimal, zero-conflict. Doesn't mention dance at all — doesn't need to. The context (being at a dance festival) does the work. Just promises an upgrade to the social side. Works everywhere because it's short and punchy.

## Copy

**Headline (large):**

> Same festival. Better crew.

**Subheadline:**

> Group dinners, carpools, roommates, and adventures — matched with dancers going to [Festival Name].

**CTA:**

> Scan to join — first 10 spots free

**QR code** → landing page with UTM `?utm_source=poster&utm_campaign=[festival-slug]&utm_content=[location]`

**Footer:**

> Rides · Rooms · Dinners · Partners · Adventures

## Design Specs

| Element     | Value                                  |
| ----------- | -------------------------------------- |
| Size        | A3 (297×420mm)                         |
| Orientation | Portrait                               |
| Background  | Dark (stands out on white venue walls) |
| Font        | Bold sans-serif, high contrast         |
| QR code     | Bottom-right, ~8cm                     |
| Colors      | Brand colors + white text              |
| Placement   | Anywhere — entrance, bathrooms, lobby  |
| Print qty   | 5-10 per festival                      |
