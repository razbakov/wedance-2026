# Policy: Data and Privacy

**Date:** 2026-04-04
**Status:** Active

## Purpose
WeDance collects data from dancers and organizers in the EU. This policy establishes baseline data handling practices to comply with GDPR and build user trust from day one.

## Intended Outcome
Users trust the platform with their data. The organization handles personal data responsibly and legally. No data surprises — users know what's collected and why.

## Policy Details

### What we collect:
- **Dancers:** name, email, dance styles, workshop preferences, attendance data
- **Organizers:** name, email, festival details, schedule data
- Data collected is the minimum needed for the current experiment

### What we do NOT collect (yet):
- Payment data (handled by Stripe if/when needed)
- Location tracking
- Social media credentials

### Data principles:
1. **Minimal collection** — only collect what the current experiment requires
2. **Transparent purpose** — users know why each piece of data is collected
3. **No selling** — user data is never sold to third parties
4. **Right to deletion** — users can request their data be deleted at any time
5. **Secure storage** — data stored in Firebase/Postgres with access controls
6. **Agent access** — AI agents can read platform data for their role but cannot export or share user data outside the platform

### GDPR basics:
- Cookie consent on the platform
- Privacy policy page (to be created before pilot launch)
- Data processing agreement with any third-party tools
- Breach notification process: Alex notifies affected users within 72 hours

### Before each experiment launch:
- Review what new data is being collected
- Update privacy policy if scope changes
- Ensure consent mechanism covers new data
