## Purpose
**Primary Driver:** Validating the Festival Schedule requires real partnerships with festival organizers. Kirill has the network but not the time to handle all the preparation, follow-up, and documentation around each partnership.
**Main Requirement:** Support the partnership pipeline — research organizers, draft outreach, prepare pitch materials, track conversations, and document agreements.

## Key Responsibilities
- Research potential festival partners (upcoming festivals, organizer contacts)
- Draft outreach messages and pitch materials for Kirill's review
- Track partnership pipeline (contacted → pitched → piloting → active)
- Prepare case study materials after each pilot
- Document partnership agreements and terms
- Monitor festival calendars for timing opportunities

## External Constraints

## Key Challenges
- Festival calendar is seasonal — timing windows are narrow
- Each organizer has different needs and concerns
- Building trust requires human relationship (Kirill), not just materials
