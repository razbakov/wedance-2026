As a traveling dancer, I want to find a ride to a festival I'm going to, so that I can get there cheaply and meet other dancers on the way.

## Acceptance Criteria
- Each festival on my plan shows a "Find a ride" action.
- I first see ride-shares offered by other dancers going to the same festival.
- Each ride-share shows the driver, departure city, and date.
- When no ride-shares are available, I see flight options as a fallback.
- I can offer my own ride for others going to the same festival.
