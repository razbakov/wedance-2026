# RAZ-24 — Organizer paid plans — Pro (€49/event) & Network (€199/year) billing

Pricing is marketed on /organizers, but there is **no billing/subscription implementation**, and most Pro/Network features (toolkit + insights) are themselves not built — see [WED-21](https://linear.app/wedance/issue/WED-21/partner-and-connection-matching-find-a-partnerfriends-before-a) and [WED-22](https://linear.app/wedance/issue/WED-22/organizer-insights-dashboard-demand-stylelevel-mix-geography-post). Needs a payment/subscription system.
**Covers 2 landing promises — full stories below.**

---

### P730 — Organizer Pricing: Upgrade to Pro for the full engagement toolkit

As an event organizer, I want to upgrade to the Pro plan for a single event, so that I get the full set of tools to engage dancers around that event.

## Acceptance Criteria

* The Organizers page shows a Pro plan priced at €49 per event.
* The Pro plan is described as the full engagement toolkit.
* The Pro plan lists the extra features I get beyond the free Starter plan.
* I can choose the Pro plan for a specific event and see what that event unlocks.

### P731 — Organizer Pricing: Choose the Network plan for multiple events

As an event organizer running several events, I want an annual Network plan, so that I can cover all my events under one yearly price instead of paying per event.

## Acceptance Criteria

* The Organizers page shows a Network plan priced at €199 per year.
* The Network plan is described as being for organizers running multiple events.
* The Network plan lists what is included across all my events for the year.
* I can choose the Network plan and apply its benefits to more than one event.
