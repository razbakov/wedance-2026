# RAZ-22 — Organizer insights dashboard — demand, style/level mix, geography, post-event signal

The organizer insights/analytics dashboard — marketed on /organizers but **not built**. It's the core value of the paid tiers. Depends on real attendee data (accounts + plans + tickets) existing first.
**Covers 5 landing promises — full stories below.**

---

### P718 — How it works: You get insights

As an organizer, I want real data about demand, audience, and post-event feedback, so that I can plan future editions with evidence instead of guesswork.

## Acceptance Criteria

* The fourth step explains that I receive real demand data, audience geography, and post-event signal.
* I can see which workshops attracted the most interest.
* I can see where my attendees are travelling from.
* I can see feedback signal after the festival ends.

### P725 — Insights: Workshop demand

As an organizer, I want to see which workshops are trending before I finalize my schedule, so that I can shape the program around real demand.

## Acceptance Criteria

* My insights show which workshops dancers are adding to their plans.
* I can see relative demand across workshops for my festival.
* The demand view is available before the schedule is finalized.
* The organizers insights section presents workshop demand as a feature.
