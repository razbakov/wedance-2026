As a traveling dancer viewing a friend's year, I want to see which festivals we both plan to attend, so that I know where we'll cross paths.

## Acceptance Criteria
- When I view another person's year, I see how many festivals we overlap on.
- The overlap names the person I'm compared with.
- The shared festivals are listed.
- Each shared festival shows that we're both going.
- If we have no overlap, the view says so instead of showing a count.
