# CUJ & JTBD reference (WeDance 2026)

Each story in `docs/issues/` links three things:
- **P** (`p:` / filename prefix) — the promise/feature id from the Landing Promises sheet (WeDance 2026 UX).
- **CUJ** (`cuj:`) — the Critical User Journey it belongs to.
- **JTBD** (`jtbd:`) — the underlying Job To Be Done.

## Critical User Journeys (CUJ)

- **C1** — Seeker — Find your dance (first class / start dancing)
- **C2** — Student — Find your teacher (learn, styles, courses)
- **C3** — Regular — Find your floor (weekly socials, local scene)
- **C4** — Traveler — Plan your festival year (festivals, tickets, travel)
- **C5** — Pro — Take the stage / get booked (artists, gigs)
- **C6** — Host — Private event & venue
- **C7** — Organizer — Run a festival (list, ticket, insights)
- **C8** — Member — Belong & connect (onboard, account, partners, community, trust)

## Jobs To Be Done (JTBD)

- **J1** — Start dancing without feeling lost
- **J2** — Get better and keep momentum
- **J3** — Never dance alone — go with people I know
- **J4** — Plan and afford my dance travel
- **J5** — Get discovered and booked as an artist
- **J6** — Run a great event / throw a great night
- **J7** — Trust it's real — real people, real faces, no fakes
