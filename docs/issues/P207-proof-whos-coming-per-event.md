As a Dancer, I want each event to show a "Who's coming" list of real attendees, so that I can check the crowd before I decide to go.

## Acceptance Criteria
- The proof section shows an event card with a "Who's coming" area.
- The card displays real attendees for that specific event.
- Opening the event page shows the full attendee list.
- The attendees shown are people who added themselves as going or bought a ticket.
- Each event has its own separate attendee list.
