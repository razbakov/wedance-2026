As a traveling dancer, I want to see who is going to a festival before I book, so that I can decide based on who else will be there.

## Acceptance Criteria
- The Festivals page presents festivals mapped across locations.
- Each festival shows who has marked themselves as going.
- I can view a festival's attendees before deciding to book.
- I can mark myself as going so others can see me too.
